Submit a new mod

Paste your mod's GitHub repository URL. We will read mod.json from the repo for the name, description, version, tags, and platforms, then grab the .geode file from your latest release automatically. The repo has to belong to the GitHub account you are logged in as.

Your latest release needs a .geode file attached. A clean link for that file usually looks like this: https://github.com/{username}/{repository}/releases/download/{tag}/{username}.{modname}.geode for example https://github.com/geode-sdk/NodeIDs/releases/download/1.23.3/geode.node-ids.geode. Any file ending in .geode works, we just grab whichever one is attached to your latest release.
